
# University Finder

A simple and interactive web application that helps users find universities based on their country and state.

## Features

- Search universities by country.
- Filter universities by state or province.
- Fetch university data using Axios.
- Display results dynamically.
- Responsive user interface.
- Error handling for unsuccessful API requests.

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Axios
- Universities API

## API Used

http://universities.hipolabs.com/

## Project Structure

University-Finder/
- axios_project_3.html
- axios_project_3.css
- axios_project_3.js
- README.md

## How to Run

1. Clone this repository.
2. Open the project folder in VS Code.
3. Open axios_project_3.html in your browser.
4. Enter a country and optionally a state.
5. Click Get Universities.
